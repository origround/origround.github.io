# OriGround Project Website

Official project website for **OriGround: Orientation-Aware Neuro-Symbolic Zero-Shot 3D Visual Grounding** (Findings of EMNLP 2026).

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

The repository includes a manual GitHub Actions workflow that builds a static export and publishes it to GitHub Pages. After the repository is public and Pages is configured to use **GitHub Actions**, run **Deploy to GitHub Pages** from the Actions tab.
