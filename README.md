# OriGround Project Website

Official project website for **OriGround: Orientation-Aware Neuro-Symbolic Zero-Shot 3D Visual Grounding** (Findings of EMNLP 2026).

Project code: <https://github.com/origround/OriGround>

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

The repository includes a GitHub Actions workflow that builds a static export and publishes it to GitHub Pages after every push to `main`. It can also be run manually from the Actions tab.
